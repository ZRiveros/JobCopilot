# Skärmdumpar

Lägg skärmdumparna som README:n länkar till här, med exakt dessa filnamn:

| Fil | Sida | Tips |
|---|---|---|
| `annonser.png` | `/` | Rankad lista med några matchade och saknade skills synliga |
| `annons.png` | `/annonser/{id}` | Panelen ”Varför N %?” ska synas |
| `kompetensgap.png` | `/kompetensgap` | Båda listorna |
| `tavla.png` | `/ansokningar` | Kort i minst tre kolumner, gärna en uppföljning som förfallit |
| `ansokan.png` | `/ansokningar/{id}` | Steg 1–3 med prompt skapad och förhandsvisning |
| `cv.png` | Exporterad PDF | Första sidan av ett CV |

Ungefär 1400 px breda, ljust tema. Använd exempeldata – inga riktiga kontaktuppgifter.
